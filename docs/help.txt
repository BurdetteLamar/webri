
If argument [33mname[0m is given, [36mwebri[0m operates in its immediate mode,
which means that it processes that one [33mname[0m (possibly with some minor interaction),
then exits.

If argument [33mname[0m is not given, [36mwebri[0m operates in its interactive mode,
which means that enter a read-evaluate-print loop (REPL).

[1;3mNames[0m

Argument [33mname[0m is one of four types, as determined by its prefix:

|------------------|----------------|--------------------|
|       Type       |     Prefix     |      Example       |
|------------------|----------------|--------------------|
| Class/module     | Capital letter | '[94mArray[0m'            |
| Singleton method | '[93m::[0m'           | '[93m::new[0m'            |
| Instance method  | '[92m#[0m'            | '[92m#inspect[0m'         |
| Ruby file        | '[91mruby:[0m'        | '[91mruby:syntax_rdoc[0m' |
|------------------|----------------|--------------------|

Note: On the command-line, your shell may require you to escape the instance method prefix:

    [32m'\#size'[0m (instead of just [32m'#size'[0m)

[1;3mClasses and Modules[0m

To get the web page for a class or module,
type a [33mname[0m starting with a capital letter.

When the [33mname[0m is:

- The exact name of a class/module (but not the beginning of other such names):
  [36mwebri[0m opens the page for that class/module.
  Examples: '[94mArray[0m', '[94mHash[0m', '[94mStruct[0m', '[94mInteger[0m', '[94mSymbol[0m'.

- The abbreviated name of exactly one class/module:
  [36mwebri[0m asks whether to open the page for that class/module.
  Examples:

  - '[94mCov[0m'          (for '[94mCoverage[0m').
  - '[94mEng[0m'          (for '[94mEnglish[0m').
  - '[94mKer[0m'          (for '[94mKernel[0m').
  - '[94mNet::HTTP::D[0m' (for '[94mNet::HTTP::Delete[0m').}

- The abbreviated name of multiple classes/modules:
  [36mwebri[0m asks whether to open the page for that class/module;
  if Yes, [36mwebri[0m displays those names and lets you choose.
  Examples: '[94mString[0m', '[94mFloat[0m', '[94mRegexp[0m', '[94mNet::HTTP[0m'.

- Not the abbreviated name of any class/module:
  [36mwebri[0m asks whether show all class/module names.
  Examples: '[94mXyzzy[0m', '[94mNosuch[0m'.

[1;3mFiles[0m

To get the web page for a Ruby file,
type a [33mname[0m starting with '[91mruby:[0m'.

When the [33mname[0m is:

- The exact name of a Ruby file (but not the beginning of other such names):
  [36mwebri[0m opens the page for that file.
  Examples: '[91mruby:README_md[0m', '[91mruby:LEGAL[0m', '[91mruby:NEWS_md[0m', '[91mruby:syntax_rdoc[0m'.

- The partial name of exactly one file:
  [36mwebri[0m asks whether to open the page for that file.
  Examples: 
 
  - '[91mruby:maint[0m'              (for '[91mruby:maintainers_md[0m')
  - '[91mruby:syntax/assign[0m'      (for '[91mruby:syntax/assignment_rdoc[0m')
  - '[91mruby:language/pack[0m'      (for '[91mruby:language/packed_data_rdoc[0m')
  - '[91mruby:contributing/build[0m' (for '[91mruby:contributing/building_ruby_md[0m')
  - '[91mruby:optparse/arg[0m'       (for '[91mruby:optparse/argument_converters_rdoc[0m').

- The partial name of multiple files:
  [36mwebri[0m displays those names and lets you choose.
  Examples: '[91mruby:syntax[0m', '[91mruby:contrib[0m', '[91mruby:lang[0m', '[91mruby:jit[0m'.

- Not the partial name of any file:
  [36mwebri[0m asks whether show all file names.
  Examples: '[91mruby:xyzzy[0m', '[91mruby:nosuch[0m'.

[1;3mInstance Methods[0m

To get the web page for an instance method (and scroll to that method),
type a [33mname[0m starting with '[92m#[0m'.

When the [33mname[0m is:

- The exact name of an instance method (but not the beginning of other such names):

  - If that method appears in only one class/module,
    [36mwebri[0m opens the page for that class-module and scrolls to the method.
    Examples: '[92m#abbreviate[0m', '[92m#mountpoint?[0m', '[92m#xmlschema[0m'.

  - If the method appears in multiple classes/modules,
    [36mwebri[0m shows them and lets you choose; for your choice,
    [36mwebri[0m opens the page for that class-module and scrolls to the method.
    Examples: '[92m#birthtime[0m', '[92m#frozen?[0m', '[92m#owner[0m'.
 
- The partial name of multiple instance methods:
  [36mwebri[0m asks whether to show those names;
  if Yes, shows them and lets you choose; for your choice,
  [36mwebri[0m opens the page for that class-module and scrolls to the method.
  Examples: '[92m#alias[0m', '[92m#line[0m', '[92m#rm[0m'.

- Not the partial name of any instance method:
  [36mwebri[0m asks whether show all instance method names.
  Examples: '[92m#xyzzy[0m', '[92m#nosuch[0m'.
