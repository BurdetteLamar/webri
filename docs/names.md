# Quick Hits

You want the page for a class/module and know:

- Its exact class/module name.
- Its abbreviated class/module name.
- Nothing.

You want the page for a singleton method and know:

- Its exact class/module name and:

  - Exact method name.
  - Abbreviated method name.
  - Nothing about the method name.

- Its abbreviated class/module name and abbreviated method name.
- Its exact class/module name and abbreviated method name.
- Its abbreviated class/module name.
- Nothing.

You want the page for a file and know:

- Its exact file name.
- Its abbreviated file name.
- Nothing.
