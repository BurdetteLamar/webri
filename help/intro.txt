Use console application [36mwebri[0m to open a Ruby documentation page in your web browser.

Example commands:

  [1m$ webri Array[0m           Open page for class [94mArray[0m.
  [1m$ webri Enumerable[0m      Open page for module [94mEnumerable[0m.
  [1m$ webri Array::new[0m      Open page for class [94mArray[0m; scroll to method [93m::new[0m.
  [1m$ webri Array#size[0m      Open page for class [94mArray[0m; scroll to method [92m#size[0m.
  [1m$ webri ruby:README_md[0m  Open page for file [91mruby::README_md[0m.

If you're not sure of exact name, [36mwebri[0m can still help:
